02

Deadlock Conditions

The four necessary conditions that can lead to deadlock.

1

Mutual Exclusion

A resource instance can be used by only one process at a time. If it is allocated to one process, another process must wait until it is released.

Example: R1 → P1 means that instance of R1 is unavailable to P2.
2

Hold and Wait

A process holds one or more resources while waiting for additional resources.

Example: P1 holds R1 and waits for R2.
3

No Preemption

A resource normally cannot be forcibly taken from the process holding it; it is released by that process.

Example: P1 holds R1 and another process cannot simply take it.
4

Circular Wait

Processes form a cycle in which each process waits for a resource held by another process in the cycle.

Example: P1 waits for R2 while P2 holds R2, and P2 waits for R1.
